## 💼 Featured Project

### [FinSight - AI Financial Document Analyzer](https://github.com/SHAIK14/Finsight-AI) 🔥

> AI-powered RAG system for analyzing financial documents (10-K, 10-Q, earnings reports) with multi-agent verification and real-time streaming responses.

**🎯 Key Features:**
- **Hybrid Search**: pgvector (semantic) + BM25 (keyword) + Cohere reranking → **35% accuracy boost**
- **Multi-Agent System**: LangChain + LangGraph (research, verification, synthesis agents)
- **Real-Time Streaming**: Server-Sent Events (SSE) for token-by-token responses
- **Smart Caching**: Redis caching → **3s to 100ms** response time
- **Cost Optimized**: Batch embeddings → **60% cost reduction**

**🛠️ Tech Stack:**
- **Backend**: FastAPI, LangChain, LangGraph, Celery
- **Frontend**: React, Vite, Tailwind CSS, Clerk Auth
- **AI**: OpenAI (GPT-4o-mini, text-embedding-3-small), Cohere Rerank
- **Database**: Supabase (PostgreSQL + pgvector), Redis
- **Deployment**: Vercel (Frontend), Render (Backend)
